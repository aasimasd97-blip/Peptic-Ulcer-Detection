# Peptic Ulcer Detection Using Deep Learning

## Project Description

Peptic ulcer disease is a common gastrointestinal disorder that can lead to serious complications if it is not detected and treated at an early stage. Conventional diagnosis mainly relies on endoscopic examination and expert interpretation, which can be time-consuming and may vary between clinicians.

This project proposes a **deep learning and image processing-based system for automatic detection of peptic ulcers from endoscopic images**. The system performs image preprocessing, enhancement, normalization, and augmentation to improve image quality and model performance.

Transfer-learning-based deep learning architectures such as **EfficientNet-B3, ResNet50, and DenseNet121** are considered for classifying endoscopic images into **Ulcer and Non-Ulcer** categories. To improve interpretability, **Grad-CAM (Gradient-weighted Class Activation Mapping)** is incorporated to visualize the regions of an image that contribute to the model's prediction.

The system is evaluated using performance metrics such as Accuracy, Precision, Recall, F1-score, and AUC. The proposed approach aims to develop an automated, reliable, and interpretable computer-aided diagnostic system that can assist clinicians in the early identification of peptic ulcers.

## Problem Statement

- Peptic ulcer detection from endoscopic images mainly depends on manual examination and expert interpretation, which can be time-consuming and may vary between observers.
- Existing AI-based approaches have limitations, including limited focus on peptic ulcer detection, limited dataset diversity, limited clinical validation, and limited interpretability.
- Therefore, there is a need for an automated deep-learning-based system that can detect peptic ulcers from endoscopic images and classify them as **Ulcer or Non-Ulcer**.

## Proposed System

The proposed system uses deep learning and image processing techniques to automatically identify peptic ulcers from gastrointestinal endoscopic images.

The system includes:

- **Image Preprocessing:** Image resizing, normalization, and enhancement.
- **Data Augmentation:** Augmentation techniques to improve model generalization.
- **Deep Learning Models:** Evaluation of EfficientNet-B3, ResNet50, and DenseNet121 using transfer learning.
- **Classification:** Classification of images into Ulcer and Non-Ulcer categories.
- **Explainability:** Grad-CAM visualization to highlight important image regions influencing predictions.
- **Evaluation:** Performance assessment using Accuracy, Precision, Recall, F1-score, and AUC.
