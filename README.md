# Peptic Ulcer Detection Using Deep Learning

## Project Description

Peptic ulcer disease is a common gastrointestinal disorder that can lead to serious complications if it is not detected and treated at an early stage. Conventional diagnosis mainly relies on endoscopic examination and expert interpretation, which can be time-consuming and may vary between clinicians.

This project proposes a deep learning and image processing-based system for automatic detection of peptic ulcers from endoscopic images. The system performs image preprocessing, enhancement, normalization, and augmentation to improve image quality and model performance.

Transfer-learning-based architectures such as EfficientNet-B3, ResNet50, and DenseNet121 are considered for classifying endoscopic images into Ulcer and Non-Ulcer categories. Grad-CAM is incorporated to visualize the regions contributing to model predictions.

## Problem Statement

- Peptic ulcer detection from endoscopic images mainly depends on manual examination and expert interpretation.
- Existing AI-based approaches may have limitations in dataset diversity, clinical validation, and interpretability.
- An automated deep-learning-based system is needed to classify endoscopic images as Ulcer or Non-Ulcer.

## Proposed System

- Image preprocessing, enhancement, and normalization.
- Data augmentation to improve model generalization.
- Transfer learning using EfficientNet-B3, ResNet50, and DenseNet121.
- Classification into Ulcer and Non-Ulcer categories.
- Grad-CAM visualization for interpretability.
- Evaluation using Accuracy, Precision, Recall, F1-score, and AUC.
